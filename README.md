# Bloody Bounce

It is a simple game in which a knight is supposed to overcome hurdles all the while collecting gold coins to escape the dungeon he is trapped in.
It follows the theme of bounce back as it depicts how a knight, fallen into a dungeon, overcomes its setbacks with resilience and bounces them back and moves forward. 

##How to play

The controls include moving left and right using left and right arrows respectively and using space bar to jump all the while avoiding the bouncy ball.
If you touch with the ball, the game restarts to zero.
